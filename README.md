# Personal Portfolio, Tech Blog & AI Agent Platform

A modern personal portfolio website, engineering knowledge base, and content management platform. Designed with a **Modern Dark Tech & Minimalist** aesthetic, featuring a decoupled **FastAPI + SQLite** backend, a reactive **React JS + Vite + Tailwind CSS** frontend, an integrated **Technical Blog**, an interactive **AI Agent**, and a **hidden, in-app Admin Panel** with dual-mode syncing for seamless **GitHub Pages** and **Vercel** deployment.

---

## Key Features

- **Personal Portfolio:** Dynamic Profile, Work Experience, Skills Matrix, Featured Projects, Credentials & Certifications, and Contact Inquiries.
- **Interactive AI Agent:** Floating & embedded AI Assistant powered by Google Gemini (Gemini 3.8 Flash) that dynamically represents the developer to recruiters and clients using live database content.
- **Technical Blog System:** Full-featured blogging engine with formatted Markdown/HTML rendering, tag filtering, read times, and article previewing.
- **Resume JSON Importer:** One-click import that parses exported resume JSON files (Reactive Resume format) and maps them cleanly into all relational database tables.
- **Hidden Admin Panel:** Secure, unrouted in-app administration modal (`Ctrl + Shift + A`) to manage content, publish blog articles, import resume data, and review visitor inquiries.
- **Dual-Mode Architecture:** Operates dynamically connected to the FastAPI backend or gracefully client-side with offline `localStorage` fallback on GitHub Pages.
